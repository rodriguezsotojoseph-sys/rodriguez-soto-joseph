Desarrollo Web

HTML,CSS Y JavaScript:

Son tres pilares fundamentales del desarrollo web que trabajan juntos para crear paginas web dinamicas e interacctivas.

HTML se encarga de la estructura y el contenido, CSS del diseño y la presentación y JavaScript de la interactividad y funcionalidad.

Definiciones:

HTML (Hyper text Markup Language):

Es el lenguaje de marcado que define la estructura y el contenido de una pagina web. Utiliza etiquetas para delimitar diferentes elementos como párrafos, encabezados, imagenes, enlaces, etc.

CSS (Cascanding Style Sheets):

Es un lenguaje de estilos que se utiliza para controlar la presentacion de una pagina web. Permite definir aspectos como los colores, fuentes tamaños, margenes, etc., de los elementos HTML

JavaScript (Program.Language):

Es un lenguaje de programacion que permite agrefar funcionalidad interactiva a una pagina web. Permite manipular elementos HTML responder a eventos del usuario, realizar calculos, etc

Analogia de la web y una casa:

HTML

Estructura de la casa.

Es como los cimientos, las paredes, techos, y distribución de las habitaciones.

HTML define la estructura básica de una pagina web: que elementos hay(titulo, parrafos, botones, imagenes, etc). pero sin preocuparse por como se ven.

CSS

Decoración y estilo de la casa.

Es la pintura ce las paredes: el tipo de piso, los muebles, las cortinas, el diseño de la cocina.

CSS se encarga de como se ve la pagina: colores, fuentes, margenes, alineaciones, estilos responsivos... lo visual.

JavaScript

Los sistemas electricos y electronicos de la casa.

Es como los interruptores que encienden luces, las puertas automaticas, el termostato inteligente.

JavaScript añade funcionalidad e interactividad haciendo que pasen cosas como respuesta a un evento.

Resumen

"Los tres lenguajes son esenciales para el desarrollo web y cada uno juega un papel crucial en la creación de las paginas web modernas y funcionales."
